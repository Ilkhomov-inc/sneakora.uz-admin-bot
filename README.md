# 👟 Sneakora Telegram Bot

Телеграм-бот для магазина кроссовок **SNEAKORA**. 
Бот автоматически распознает модель кроссовок по фотографии или текстовому названию с помощью искусственного интеллекта (Google Gemini или OpenAI), извлекает бренд, модель, тип, цвета и оформляет готовый пост для Telegram-канала строго по вашему шаблону.

---

## 📋 Формат шаблона

```text
👟 NIKE | НОВАЯ КОЛЛЕКЦИЯ

🔥 Стиль и комфорт в каждом шаге!

✨ Характеристики:
▫️ Модель: W AIR FORCE 1 '07
▫️ Тип: Женская 
▫️ Размеры: Все размеры  
▫️ Цвет: Белый / Кремовый / Пыльно-розовый.
💰 Цена: 62$

🛍 Обнови свой стиль вместе со SNEAKORA!

📩 Для заказа: пиши в личные сообщения.

⚡ Успей заказать свою пару!

@sneakora_admin
```

> **Примечание по цене:** Если цена не указана, бот по умолчанию оставляет плейсхолдер `💰 Цена: ___$` (или можно полностью скрыть строку в настройках `.env`). Под каждым постом есть кнопка **«💰 Указать цену»**, которая позволяет моментально вписать цену и обновить пост!

## ✨ Возможности бота

1. 📸 **Распознавание по фото:** Скиньте боту фотографию кроссовок (или альбом) — нейросеть точно определит бренд, модель и цветовую гамму.
2. ✍️ **Поиск по названию:** Напишите название модели текстом (например: `Adidas Campus 00s Core Black` или `New Balance 530`) — бот найдет полные характеристики и оформит шаблон.
3. 💡 **Умные подсказки:** К фото можно прикрепить подпись, например: `женские 36-40 цена 70$` — бот автоматически применит эти параметры.
4. 📋 **Быстрое копирование:** Кнопка «Текст для копирования» выдает моноширинный блок: на смартфоне достаточно один раз нажать на текст, чтобы скопировать его целиком в буфер обмена.
5. 🛡 **Защита доступа:** Можно ограничить список Telegram ID сотрудников, чтобы посторонние не тратили запросы к ИИ.

## 🚀 Быстрый запуск

### 1. Подготовка окружения

Убедитесь, что у вас установлен Python 3.9+.

```bash
# Перейдите в папку бота
cd /Users/azizbekilhomov/.gemini/antigravity/scratch/sneakora_bot

# Создайте и активируйте виртуальное окружение
python3 -m venv venv
source venv/bin/activate

# Установите зависимости
pip install -r requirements.txt
```

### 2. Настройка файла `.env`

Откройте файл `.env` в любом редакторе и укажите:

```ini
# Токен бота из @BotFather
BOT_TOKEN=123456789:ABCdefGHIjklMNOpqrSTUvwxYZ

# Выбор ИИ (gemini или openai)
AI_PROVIDER=gemini

# Бесплатный ключ Gemini (получить на https://aistudio.google.com/)
GEMINI_API_KEY=AIzaSy...
GEMINI_MODEL=gemini-2.5-flash

# Настройки магазина
SHOP_NAME=SNEAKORA
ADMIN_HANDLE=@sneakora_admin

# Режим цены (placeholder - выводит "💰 Цена: ___$", omit - скрывает строку цены)
PRICE_MODE=placeholder

# Список ID сотрудников через запятую (оставьте пустым для открытого доступа):
ALLOWED_USERS=
```

#### Где взять ключи:
- **Telegram Bot Token:** Откройте [@BotFather](https://t.me/BotFather) в Telegram, отправьте команду `/newbot` и скопируйте выданный HTTP API Token.
- **Google Gemini API Key:** Зайдите на [Google AI Studio](https://aistudio.google.com/), нажмите **«Get API key»** и скопируйте ключ (доступен бесплатный тариф).

### 3. Запуск бота

```bash
# Активация виртуального окружения (если еще не активировано)
source venv/bin/activate

# Запуск
python3 main.py
```

## 💡 Полезные советы для команды

- **Публикация в канал:** Бот отправляет фото сразу с готовой подписью. Вы можете просто нажать «Переслать» (Forward) в канал магазина без автора!
- **Если модель редкая:** Если нейросеть сомневается, просто отправьте фото с уточнением в подписи (например: `Nike Dunk Low SP Plum`).
- **Смена режима цены:** Если вы вообще не хотите видеть строку цены в черновике поста, установите в `.env`:
  ```ini
  PRICE_MODE=omit
  ```
